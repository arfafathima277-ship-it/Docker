# Docker Commands

## Check Docker Version

```bash
docker --version
```

Displays the installed Docker version.

---

## Display Docker Information

```bash
docker info
```

Shows detailed information about the Docker Engine, including:
- Number of containers
- Number of images
- Storage driver
- CPU and Memory
- Docker Root Directory
- Server information

---

## List Docker Images

```bash
docker images
```

or

```bash
docker image ls
```

Displays all images available on the local machine.

Example Output:

REPOSITORY | TAG | IMAGE ID | CREATED | SIZE

---

## Download an Image

```bash
docker pull <image-name>
```

Example:

```bash
docker pull ubuntu
docker pull nginx
```

Downloads an image from Docker Hub.

---

## Run a Container

```bash
docker run <image-name>
```

Example:

```bash
docker run ubuntu
```

Creates and starts a new container from the specified image.

---

## Run a Container in Interactive Mode

```bash
docker run -it ubuntu
```

Options:

- `-i` → Interactive mode
- `-t` → Allocate a terminal

Allows users to interact with the container through the command line.

---

## Run a Container in Detached Mode

```bash
docker run -d nginx
```

Option:

- `-d` → Detached mode

Runs the container in the background.

---

## Assign a Name to a Container

```bash
docker run -d --name mynginx nginx
```

Assigns a custom name instead of a randomly generated one.

---

## List Running Containers

```bash
docker ps
```

Displays only running containers.

---

## List All Containers

```bash
docker ps -a
```

Displays both running and stopped containers.

---

## Start a Stopped Container

```bash
docker start <container-id>
```

Starts an existing stopped container.

---

## Stop a Running Container

```bash
docker stop <container-id>
```

Gracefully stops a running container.

---

## Restart a Container

```bash
docker restart <container-id>
```

Stops and starts the container.

---

## Remove a Container

```bash
docker rm <container-id>
```

Deletes a stopped container.

---

## Remove an Image

```bash
docker rmi <image-name>
```

Deletes an image from the local system.

Note:
An image cannot be removed if it is being used by a container.

---

## Execute Commands Inside a Running Container

```bash
docker exec -it <container-id> bash
```

Opens a terminal session inside a running container.

---

## View Container Logs

```bash
docker logs <container-id>
```

Displays application logs generated by the container.

---

## Inspect a Container

```bash
docker inspect <container-id>
```

Shows detailed information in JSON format, including:
- Network settings
- IP address
- Mount points
- Environment variables
- Container configuration

---

## Display Running Processes

```bash
docker top <container-id>
```

Shows the processes currently running inside a container.

---

## Display Resource Usage

```bash
docker stats
```

Displays live CPU, memory, network, and disk usage of running containers.

---

## Remove Stopped Containers

```bash
docker container prune
```

Deletes all stopped containers.

---

## Remove Unused Docker Resources

```bash
docker system prune
```

Removes:
- Stopped containers
- Unused networks
- Unused images
- Build cache

To remove all unused images as well:

```bash
docker system prune -a
```

Use this command carefully because deleted resources cannot be recovered.

---

| docker ps | List running containers |

| docker stop | Stop a container |

| docker restart | Restart a container |
| docker rm | Remove a container |
| docker rmi | Remove an image |
| docker exec -it | Access a running container |
| docker logs | View container logs |
| docker inspect | Display detailed container information |
| docker stats | Display resource usage |
| docker system prune | Remove unused Docker resources |
